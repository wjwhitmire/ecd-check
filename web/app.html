        Method and limits

        Model: API RP 13D, Third Edition (June 1995), power-law annulus. Units: ppg, gpm, in, ft, cP, psi. Dial readings in degrees on a standard R1-B1-F1 rotational viscometer.

        n_a = 0.657 log10(R100 / R3) K_a = 5.11 R100 / 170.2^n_a dyne s^n / cm^2

        When only 600 and 300 rpm are known (always the case with PV/YP, where R600 = 2 PV + YP and R300 = PV + YP), the annulus uses the 600/300 power law and the result says so:

        n = 3.32 log10(R600 / R300) K = 5.11 R300 / 511^n Va = 24.48 Q / (D2^2 - D1^2) ft/min (0.408 Q / (D2^2 - D1^2) ft/s) mu_ea = 100 K_a (144 Va / (D2 - D1))^(n_a - 1) ((2 n_a + 1) / (3 n_a))^n_a cP, Va in ft/s Re_a = 928 (D2 - D1) Va MW / mu_ea Va in ft/s laminar Re_a < 3470 - 1370 n_a f = 24 / Re_a turbulent Re_a > 4270 - 1370 n_a f = a / Re_a^b, a = (log10 n_a + 3.93)/50, b = (1.75 - log10 n_a)/7 transitional between: f linear in Re_a between the laminar f at the lower bound and the turbulent f at the upper bound dP = f Va^2 MW / (25.81 (D2 - D1)) L psi, Va in ft/s P_hyd = 0.052 MW TVD ECD = MW + APL / (0.052 TVD) BHCP = P_hyd + APL

        Limits, stated plainly:

        • Isothermal, incompressible fluid. Rheology is taken as measured at surface; downhole temperature and pressure change it.
        • Concentric annulus, no pipe rotation, no tool joints, no eccentricity. Real laterals with eccentric pipe usually lose less in laminar flow than this predicts.
        • No cuttings load, no surge/swab, no gel breaking. ECD is for steady circulation with clean mud.
        • All of the listed annulus pressure loss is applied at the given TVD. List only the sections above the point of interest.
        • The 1995 transitional friction factor is a straight-line blend. Across the transition band, computed loss can fall as rate rises. The chart shades that band.
        • Power law has no yield stress. With PV/YP only, low-shear behavior is not represented and annular loss in large, slow annuli is usually under-predicted.
        • The 2006 and later editions of API RP 13D use the Herschel-Bulkley model and different regime criteria. Results will differ.
